# Build Systems

In this exercise, we will build our FSK Checker project using Bazel. FSK ratings indicate the appropriate age groups for viewers, helping parents and audiences make informed decisions about the content they or their children are about to watch.

This exercise aims to enhance your basic understanding of [Bazel](https://bazel.build/docs#basics) and its functionality.

Requirements for this exercise:

1. [Bazelisk](https://bazel.build/install/bazelisk) should be installed on your system. Make sure that you are using Bazel 7 or later.
2. Learners should be familiar with Java and Bazel for better understanding.

**Note for Bazel 7+:** Bazel's `WORKSPACE` file is being replaced by `MODULE.bazel`. To use it, enable the module system via a `.bazelrc` file with `common --enable_bzlmod`.

## General

In Bazel, a `java_library` rule in a BUILD file is used to define a Java library target. It specifies how Java source files should be compiled and packaged into a library that can be used by other parts of your project or other projects that depend on it. Similarly, the `java_binary` rule defines a binary target for a Java application. It specifies how Java source files should be compiled, dependencies linked, and an executable JAR file or other binary output created.

1. **date_of_birth package built correctly**

    Implement a `java_library` rule for the `DateOfBirth` class in the BUILD file located inside src/main/java/math with the target name: date_of_birth. It should be visible only within the package.

2. **movie library built correctly** 

    Implement a `java_library` rule for the `Movie` class in the BUILD file located in the root directory of the exercise with the target name: movie.

    **Hint:** This test will only pass after the Combined Dependency test has been completed.

3. **Combined Dependency test**

    Implement the `java_binary` rule in the BUILD file located in the root directory of the exercise with the target name: `fsk_checker`.

    **Hint:** Don’t forget to set the dependencies with respect to their locations.

4. **Compilation and Build**

    Correctly compile your project using Bazel and generate an executable file named `fsk_checker` in the **./bazel-bin** directory.
    Putting it all together, `bazel build //:target_name` tells Bazel to build the specified target named target_name in the BUILD file located at the root of your Bazel workspace. Bazel will then follow the dependencies, compile the necessary source files, and create the output specified by the target, such as an executable binary or a library in the **bazel-bin** folder.

After successfully building the FSK Checker project with Bazel, you can run the executable file generated by Bazel, located in the bazel-bin directory, using the following command: `./bazel-bin/fsk_checker`

**Note:** If you receive a `Project SDK is not defined` error after running `make build`, try running `bazel build --java_runtime_version=remotejdk_17 //:fsk_checker` in the command line.
